星火与道路 · 工人运动时空叙事
==============================

【怎么打开】

Windows 10/11 64 位（推荐，零安装）：
    双击  启动（免安装）.bat
    浏览器会自动打开 http://127.0.0.1:8790/index.html

已经装过 Python 的任何系统：
    双击  启动展馆.bat        （Windows）
    或命令行：cd 本目录 && python -m http.server 8790
    然后打开 http://127.0.0.1:8790/index.html

Mac / Linux：
    终端执行：cd 本目录 && python3 -m http.server 8790
    浏览器打开 http://127.0.0.1:8790/index.html
    （tools/caddy.exe 只适用于 Windows；Mac/Linux 可从 caddyserver.com 下载对应版本，
      用同样的 Caddyfile 启动，或直接用 Python）


【千万不要双击 index.html】

浏览器在 file:// 协议下会拦截 fetch，模型、清单、文献页都加载不出来——
页面看起来能开，实际上所有数据都是空的。必须用上面的本地服务打开。


【三种模式】

    电影导览    http://127.0.0.1:8790/index.html?tour=1
    自由漫游    http://127.0.0.1:8790/enter.html
    研究档案    http://127.0.0.1:8790/assets.html

页面底部有一枚切换胶囊，随时可以在三种模式之间跳。


【展示终端 / 大屏】

任意页面加 ?kiosk=1，会隐藏顶栏、侧栏和浮层，只留展馆内容。
按 Esc 退出。


【常见问题】

1. 提示端口被占用
   启动脚本会自动从 8790 往上找空闲端口，窗口里会打印实际地址。

2. 打开后是白屏或模型不显示
   确认地址是 http://127.0.0.1:端口/ 而不是 file:///
   再按 Ctrl+F5 强制刷新（浏览器可能缓存了旧版脚本）。

3. 3D 场景很卡
   集显笔记本正常现象。可以把窗口缩小，或改用 scenes.html（证据目录，纯图文）。

4. 视频在哪
   video/out/ 下有 1080p 成片；交付包的 03_视频/ 里是全部成片。
