# 字体说明

本站使用两款 Aa 字体，均标注「非商业使用」。**课程作品可用，转商用必须替换。**

| 用途 | 字体 | 文件 | 体积 |
|---|---|---|---|
| 展示级标题（首页主标题、章节大标题、展示模式、单件页、内页页头） | Aa润行体（9123） | `aa-runxing.woff` / `.ttf` | 165 KB / 248 KB |
| 数字与卷号（202、9、48、12、7、01–11 等） | Aa厚底黑（9114） | `aa-heavy.woff` / `.ttf` | 7 KB / 10 KB |

正文字体不受影响，仍为宋体，避免通篇过于「软」。

## 处理过程

1. **子集化**：只保留站点实际出现的 341 个字（标题用字，从 HTML 标题、展示模式章节名、叙事章节名中提取），字形数从 7,868 降到 341。
2. **修复 OTS 拒绝**：原字体直接引用会被 Chrome 拒绝：

   ```
   OTS parsing error: vhea: Unsupported table version: 0x10001
   vhea: Failed to parse table
   ```

   删掉 `vhea` / `vmtx`（竖排度量，本站不用竖排）后即可加载。
3. 十个 Aa 字体逐个测试，只有厚底黑、玩手机可练字体能直接过校验；润行体修复 vhea 后可用。最终选用润行体（标题）+ 厚底黑（数字）。

## 应用位置

| 选择器 | 字体 |
|---|---|
| `.hero h1` | 润行体，字号 clamp(34–68px)，`text-wrap:balance` |
| `.chapter-head h2` | 润行体，字距 0.015em |
| `.slide h1/h2` | 润行体；展示页内容垂直居中 |
| `.side h1`（单件页） | 润行体 |
| `body > header h1`（史料墙等内页） | 润行体，字号提到 21–27px |
| `#nums b`、`.count b`、`#n`、`#total`、卷号 | 厚底黑 + `tabular-nums` |

## 替换方法

1. 把新字体放进本目录；
2. 改 `css/calligraphy.css` 里 `@font-face` 的 `src`；
3. 若浏览器报 OTS 错误，用 fontTools 删 `vhea`/`vmtx` 并重新子集化：

```python
from fontTools import subset
font = subset.load_font(src, opts)
s = subset.Subsetter(options=opts); s.populate(text=chars); s.subset(font)
for t in ("vhea", "vmtx"):
    if t in font: del font[t]
font.flavor = "woff"; font.save(out)
```
