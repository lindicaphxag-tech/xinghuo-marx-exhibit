# 离线文献资料

本目录中 `covers/` 存放现有文献与馆藏图像封面。本地新增的研究全文包及来源、许可、年份范围、SHA-256、覆盖局限见 [`research_manifest.json`](research_manifest.json)。展馆的报刊卷已经能读取 [`bee-hive/index.json`](bee-hive/index.json)，按期加载 1862/1872 两年选集全文。

当前实际打包两份英国图书馆 The Bee-Hive 报纸 OCR/元数据压缩包（1862、1872），资源页将数据标为 CC0 1.0。生成后的离线阅读索引覆盖 65 个日期期次、4,780 篇文章；数据包是已数字化年份的选集，不是整份刊物连续完整的卷期扫描，也不是页面图像 facsimile。引用时应回到包内的条目元数据并注明英国图书馆与 DOI。可用 `python scripts/import_beehive.py` 从原始 ZIP 重建逐期 JSON 阅读数据。

巴黎档案馆提供的公社年表、1871 年巴黎地图，以及英国国家档案馆的 Chartism 教学档案仍使用官方在线入口。档案馆页面允许下载并不自动表示可再次公开分发；版权/复用条款核验前不镜像进离线包。
