# 历史空间三维模型

本目录中的 GLB 均可在展馆中交互查看。场景数据性质分为现存遗址扫描、现存建筑扫描来源、当代 LiDAR 地形/表面和史料约束复原；巴黎会议室条目不再放置概念几何。程序化模型不等于实景扫描，也不应当作工程测绘成果。

## 展厅中的视角与现场对照

- 本地 GLB 场景可以使用“斜视、俯视、近景、重置视角”预设；鼠标仍可环绕、平移和缩放。
- 具有 `paired_scene_id` 的地点会在模型上方出现“同址证据对照”快捷按钮，例如 Mytholme Mill 遗址摄影测量与当代 LiDAR、肯宁顿公地复原与当代裸地地形、旧市政厅复原与现存重建建筑扫描。配对只表示地点或主题可对照，不表示两个模型是同一年代或同一精确建筑轮廓。
- 进入来源站扫描或在线点云时，视角预设会隐藏；它们由来源站或独立点云查看器控制。受许可限制或源站不提供下载的网格仍只嵌入/外链，不复制到本地。
- 当前16条条目包含11个本地 GLB（7个史料约束复原、4个当代 LiDAR DSM/地形表面）、3个来源站摄影测量扫描，以及巴黎现状点云、室内/街景全景和现址三维地图入口。数量不代表所有历史地点都有事件当年的实扫；已毁建筑和无公开实扫的内部继续以史料约束复原或现状对照呈现。外部地图入口仅打开原平台，不把平台影像复制到本地。

“现存遗址扫描”按扫描采集年代命名，不表示它扫描了历史事件发生当年的现场。例如 Mytholme Mill 页面中的摄影测量记录的是2017年考古发掘前仍存的遗址，因此数据类型标为 `present-day-archaeological-scan`，并与1779年原厂状态明确区分。遗址已毁、建筑已改建的空间，不可能再有原年代现场扫描；这类内容只能在取得足够史料后做可复核的历史复原，同时另列当代实测场景。

## 可交互本地复原模型

- `hotel_de_ville_pre1871.glb`：1871 年前巴黎旧市政厅复原，依据巴黎博物馆联盟 PM55/PM57 馆藏比例模型及描述；表现八个亭楼、三座庭院、玻璃顶庭院与河岸花园。由主展馆旧市政厅条目加载。独立文件名用于避免与现存市政厅扫描条目混淆。
- `chartist_kennington_common.glb`：1848 年肯宁顿公地开放集会空间关系复原，依据基尔伯恩银版照片；另可切换查看公园现存纪念柱的 CC BY 摄影测量扫描。地形和人群都不代表精确测绘/人数。
- `paris_1848_street.glb`：1848 年圣马丁街垒街景复原，已按卡纳瓦莱 D.8384 原图重排横贯街道的石块、横木和翻倒手推车，并增补图中可见的马匹提示。馆藏只定位到圣马丁街第三区/第四区，不给出精确街口；模型不是实测或摄影测量。CC0原图本地文件及地理精度边界见 `sources/paris-1848-saint-martin-barricade.json`。
- `shanghai_machine_weaving_bureau.glb`：上海机器织布局（1889—1893）主厂房比例复原，依据约550×80英尺、三层的后出工业史记载；内部设备布置属示意剖面。旧址在杨树浦路，旧门牌87号对应后续门牌1900号一带；澳门路150号为迁址后的申新九厂。
- `first_international_printshop.glb`：圣马丁堂成立大会会堂，按《The Builder》1853年完整主厅记载的长宽高缩放；1850年前后版画作为早期室内参照，座席与1864年具体布置属于复原解释。
- `marx_reading_room.glb`：大英博物馆圆形阅览室的环形书库、径向阅览桌与肋骨穹顶空间研究；并非马克思在场时的扫描。
- 巴黎公社公告与会议地点尚未定位到可验证的房间，已撤下概念室内 GLB；该条仅链接巴黎市政厅火灾后重建建筑的现状室内全景，不能当作公社时期现场。
- `memory_archive_hall.glb`：斯莫尔尼学院主楼外观的尺度研究模型，不是相邻斯莫尔尼大教堂的扫描。

斯莫尔尼主楼模型现以夸伦吉约1806—1808年主立面中段/墙体详图、圣彼得堡建筑史中“中央八柱门廊”的记载及现状照片共同约束，并补入现状立面连续拱券。艾尔米塔什藏原图不等于完整平面或1917年室内扫描；展厅时间线另行区分革命总部时期与1923—1934年入口、纪念像、喷泉改造。著录、许可与几何使用边界见 `sources/smolny-institute/quarenghi-drawing.json`，原图可在展厅证据栏切换查看。

大英博物馆圆形阅览室新增馆方团队制作的教学 3D 数字表示外链（Centre for Digital Media 项目档案）。项目页没有说明它通过现场扫描制作，也没有写明可下载/再利用许可；它目前是历史项目说明页，不保证仍有可运行模型，因此只标为项目档案、不宣称可进入实时3D。近180°真实室内拼接全景另在 `reading-room-panorama.html` 提供拖动、缩放浏览，影像仍从 Wikimedia Commons 远程加载，网络不可用时页面会给出原档案入口；这不是三维网格。来源核查记录见 `sources/british-museum-reading-room-3d.json` 和 `sources/british-museum-reading-room.json`。本地模型仍是按1868年读者手册尺寸约束的教学复原，2006年全景与2025年照片分别标明各自年代。

巴黎旧市政厅条目新增 Collard 于1871年拍摄的火灾后废墟照片，来源为大都会艺术博物馆藏品59.600.59及 Wikimedia Commons CC0 文件。照片是灾后原始二维史料；它与 PM55/PM57 火灾前比例模型、现存重建建筑扫描构成不同年代的证据对照，不作为可测量的三维几何。图像许可和对象信息见 `sources/hotel-de-ville-ruins-1871.json`。

巴黎旧市政厅复原条目补充维也纳技术博物馆的两条玻璃立体照片馆藏记录：一条题为“Hotel de Ville de Paris”，另一条题为“Rue de Rivoli und Hotel de Ville, Paris”。目录确认其为17×8.3厘米玻璃立体照片，但未著录拍摄年代，现有文字也不足以判断画面拍摄于1871年火灾前还是重建后。因此只作为可追溯的历史影像线索链接，不直接下载、不冒充旧楼扫描，也不用于推定复原几何；若未来馆方补齐年代、摄影者或可视化原图，可再据证据调整场景。

### 拉雪兹神父公墓纪念碑：把扫描放回正确地点

巴黎公社区新增独立展项“革命遇难者纪念碑（1909实景扫描）”。原先它被列在市政厅广场的相关模型中，观众容易把纪念碑误当成1871年现场。现改为独立 Sketchfab 摄影测量嵌入，署名 Antoine Dresen，模型页标注 CC BY 4.0；定位在公墓北侧 Samuel-de-Champlain 纪念园（约 2.3908, 48.8638）。巴黎市政府资料确认：公社最后战斗与处决发生在公墓，纪念碑则是1909年建在公墓另一侧的后世纪念物。时间线和说明明确区分“事件现场 / 联邦社墙 / 1909纪念碑 / 当代扫描”。此扫描展示真实现存纪念物，不能代表1871年处决墙或现场。来源分别见该展项的 Sketchfab 页面与巴黎市政府公墓史说明。

2026-11-01 通过 Sketchfab 官方公开 API 再查 Smolny、St Martin’s Hall、上海机器织布局、大英博物馆阅览室与拉雪兹纪念碑：未命中前三处精确场景扫描；“Smolny” 命中的是相邻大教堂，排除；阅览室关键词只命中无关浮雕。纪念碑搜索另找到 1.87M 与 5.46M 面的同题模型，当前嵌入版本为 449,931 面，是可核候选中较轻的版本。官方 API 的下载接口仍需授权；展馆不抓取网格。完整查询词、命中对象、排除依据及检索范围限制记录在 `sources/sketchfab-site-scan-search-20261101.json`。这轮面数比较不能证明其它平台没有更轻的扫描。

## 外部实景模型

Mytholme Mill 遗址、巴黎现存市政厅和拉雪兹公墓1909年革命遇难者纪念碑由来源站提供交互扫描。扫描对应的是现存遗址/后世纪念物，不是运动发生年代的原场景；受各来源许可约束，展馆不把外部模型下载或保存成本地副本。若外部查看器不可用，界面显示来源说明，不以历史复原模型冒充现状扫描。巴黎现存市政厅是 1871 年火灾后的重建建筑；与旧市政厅复原条目并列，不能混为同一年代。

巴黎公社公告与会议地点尚未能定位到具体房间。已从清单、构建脚本和发布目录中移除未经史料约束的会议室概念几何；对应条目改为现存巴黎市政厅内部全景对照。巴黎市政府说明全景可以从广场进入并切换楼层，室内装饰重建于1871年火灾后；此全景不能证明公社时期房间布局。若未来取得旧楼平面图、室内影像或档案，再独立重建历史空间。

圣马丁堂旧址的现状空间新增 Google Earth 外链，可从地址打开伦敦街区现状三维影像；具体影像日期与建筑细节随平台数据而异，用户需在平台中核对。它与本地环境署 LiDAR DSM 互补，但不是旧堂扫描，也不能替代1864年会堂复原。许可仅允许按原平台使用，因此不下载或本地镜像；记录见 `sources/long-acre-google-earth-3d.json`。

圣马丁堂条目补入伦敦档案馆藏1847年音乐厅原始设计木刻目录，档案编号 SC_PZ_WE_01_1644。目录年代、出版物与媒介可核验，但地图定位标注为近似，高清复用需另行申请许可；而且它属于火灾前原建筑设计，不能直接充当1853年完整大厅或1862年重建后的1864年会堂图纸。本地场景因此继续标为史料约束复原，不标成原址实扫或完整测绘。

## 构建

`build_history_scenes.py` 使用 Python、NumPy 和 trimesh 生成 GLB：

```powershell
py scripts/build_history_scenes.py assets/scenes
```

几何随新测绘、平面图、立面图和馆藏资料继续校正。证据范围和不确定性在 `scenes.json` 中逐条记录，并在展馆说明区呈现。


## 2026-11-01 模型可视化修复

- 修复 Trimesh 导出时重复 `geom_name` 覆盖同类构件的问题；此前重复窗、柱、织机和人群会在 GLB 中只留下最后一个实例。上海机器织布局主厂房由 148 顶点 / 236 面恢复为约 14,510 顶点 / 24,348 面。
- 展厅按缩放后的模型包围范围自动设置初始观察距离，并缩放平移量后居中，避免长条厂房偏离视野、模型缩成远处小点。
- 这些修复改善的是模型几何完整性和查看体验，不能把程序化模型升级为现场扫描。现场扫描仍须有现场原始影像、采集记录、处理过程与许可证明。

## 巴黎现状点云对照层（2026-11-01）

- 巴黎市政厅与旧市政厅两条场景均可从说明面板内按市政厅坐标打开约240米的 IGN LiDAR HD 实测点云。该点云是现状区域表面数据，以单色点显示；不是建筑纹理网格，不表示历史年代，也不覆盖历史建筑内部。
- 1848年圣马丁街垒复原新增 Rue Saint-Martin 163号附近的同街名片区 LiDAR 入口。馆藏图没有定位具体街口，所以该点云只用于观察一处当代街区地表/屋顶，明确不当作街垒准确原址，也不代表1848年街景。来源同为 IGN LiDAR HD / Licence Ouverte 2.0。
- 查看器版本、许可证、点云来源、坐标与数据边界见 `scenes/sources/ign-paris-lidar.json`；依赖与署名文本见 `vendor/lidar-viewer-1.0.0/`。
- 拉雪兹公墓联邦社墙增设独立“现状 LiDAR”展项，在线按墙址附近坐标请求约240米点云。它与公墓外约1公里处的1909年革命遇难者纪念碑扫描分开呈现；点云不证明当代墙体与1871年墙体相同，也不替代历史墙体复原。

## 旧市政厅馆藏比例模型的摄影测量复核（2026-11-01）

- 为避免文件名误导，火灾前旧市政厅的本地历史复原资源独立命名为 `hotel_de_ville_pre1871.glb`，由 `build_history_scenes.py` 中的旧市政厅复原函数生成；巴黎现存市政厅摄影测量只从原发布平台加载，不保留错误复制的复原 GLB。
- 对 PM57 木质馆藏模型的 22 张 CC0 照片运行 COLMAP 4.2.1：10 张照片注册、得到 2,886 个稀疏点，但点云仅覆盖馆藏模型局部，外包围盒比例也与馆藏实物 32 × 42.5 × 29 cm 不符。没有发布该残缺点云，也没有把它解释为旧市政厅全尺寸扫描。
- PM55 的既有试建结果仍为 47 张照片中 4 张注册、515 个稀疏点。两次尝试都不足以生成可用的馆藏模型网格；结果与命令环境记录在 `sources/hotel-de-ville-pm55/reconstruction-assessment.json`。

## Mytholme Mill 遗址当代 LiDAR DSM 网格

`mytholme_mill_current_dsm.glb` 与 Mytholme Mill 的外部摄影测量实扫配对。Sketchfab 作者为 PBarrett；页面说明该模型拍摄于2017年4月考古发掘前，标注约26.2万三角面及 CC BY-NC-ND 许可。展馆从原作者查看器加载，未下载、改编或镜像；如果设备无法渲染，可切换到配对的 LiDAR 表面层。现状 DSM 是环境署 1m 源数据裁成600m方形表面、2m抽样、垂直比例1:1，约9万顶点；它只显示屋顶、树冠与地表上表面，不是立面或内部扫描，也不代表1779年原貌。数据来源、OGL v3.0许可与范围见 `sources/mytholme-mill-current-dsm.json`；用 `python scripts/build_mytholme_dsm.py` 重建。此前本地低模厂房剖面已移除，避免与实景扫描混淆。

上海机器织布局复原补充证据：该条目现在包含上海纺织博物馆内实体机器织布局比例模型的一张照片（Coolmanjackey，2013-08-03，CC BY-SA 3.0）。单张实拍只作为整体外观参照，不是建筑扫描，也不足以重建背面或精确尺寸；授权与边界见 assets/scenes/sources/shanghai-machine-bureau-scale-model.json。

上海杨浦工业带新增杨树浦电厂 Sketchfab 三维模型来源入口（Tigershill，模型页未注明扫描/重建方法，也没有可复用许可声明），只链接原站，不下载或嵌入复制。它仅供了解杨浦滨江工业遗产的地区背景：上海市政府资料将电厂遗址定位于杨树浦路2800号并记载其1911年建立；机器织布局旧址约在杨树浦路1900号一带，两者是不同地点与建筑，不能将电厂模型当作机器织布局实扫。模型来源页和官方位置/年代来源均列在场景说明中。

上海纺织博物馆还曾向世界技能博物馆提供一组机器织布局重建系列照片；公开报道指其中有1933年收购三新纱厂时拍摄的同址照片。该组影像可成为进一步做多视角摄影测量的档案线索，但目前没有找到可公开下载的完整高清照片组与逐张使用许可，不能把报道中的单张配图扩作扫描模型。1933年的厂区也经历了1893年火灾后的沿革，不能与1889年初建现场混为同一时间切片。原始藏品线索与使用边界已在 `scenes.json` 的上海场景来源栏注明。

- 用 COLMAP / pycolmap 4.2.1 对原17张照片进行 SIFT 特征匹配与增量重建：21组通过几何验证、连通分量12张，最终仅2张注册、31个稀疏点。再加入两张2022年侧/端立面照后，19张自动相机模式仍只注册原来的2张、31点；新照片之间虽有56个几何内点，强制两图初始化仍生成0个模型。未产出可发布全楼或局部网格；不能称作摄影测量扫描。
- 评估与图像来源清单见 `sources/smolny-institute/photogrammetry-assessment.json` 和 `candidate-photos.json`。为保持项目轻量，临时特征数据库和重建缓存已清理；正式展馆只保留经许可的预览图与可追溯来源记录。
- 斯莫尔尼与上海长立面现已按约60米立面段设置初始镜头，仍可缩放查看完整建筑；这是视角优化，不改变复原模型的证据属性。
