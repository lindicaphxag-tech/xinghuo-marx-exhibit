## 三、交互与性能分寸

- **进入视口才初始化**（IntersectionObserver，阈值 0.2），离开视口即停止渲染 —— 不占 GPU
- `autoRotate` 缓慢自转（0.9），可拖动旋转、滚轮缩放，禁止平移（避免把物体拖丢）
- 三个模型共用同一个场景与光照，切换时**主动 dispose** 几何体、材质与贴图
- 光照克制：环境光 + 主光 + 一道暗红色轮廓光（呼应全站红黑基调），不做泛光/辉光

## 四、已知限制

1. **没有法线**：`computeVertexNormals()` 补出来的法线在薄壁（书页）处会有硬边。
2. **背面是猜的**：单图生成看不到的地方由模型补全，转 180° 会看到明显的"另一张脸"。
3. **不能用尺寸**：没有真实比例尺，页面已标注。
4. `file://` 直接双击打开会被浏览器拦截（CORS），要起本地服务器：
   ```powershell
   python -m http.server 8000 --directory "C:\Users\HUAWEI\Desktop\马原\沉浸式宣讲数字展馆"
   ```

## 五、怎么加更多文物

1. 在服务器上：
   ```bash
   /root/run_triposr.sh /root/in/新图.jpg
   ```
   （依赖：`torchmcubes` 编译失败时用 PyMCubes shim，见 `/root/autodl-tmp/TripoSR/torchmcubes.py`）
2. 下载 `mesh.glb` 到 `assets/models/`
3. 在 `js/scenes/artifacts.js` 的 `MODELS` 数组里加一条（id / name / file / meta / note）即可，按钮自动生成

## 七、实测质量记录（2026-10-31）

在 RTX 3080 Ti 上跑 TripoSR，输入用素材库里的三张单图，输出用 pyrender 渲染成 PNG 对照：

| 输入 | 结果 | 判断 |
|---|---|---|
| `07_trier_bust.JPG`（特里尔胸像） | 能看出胸像轮廓、胡须与底座，**面部糊成一团** | 可用作远景，不可近看 |
| `08_bust_cc0.jpg`（CC0 胸像） | 人像 + 方形基座，基座被"糊"成一体 | 一般 |
| `01_manifest_1848_cover.jpg`（初版扉页） | **退化成一堆漂浮碎面** | 失败，已从展示里剔除 |

结论（写进报告可以直接用）：

1. **单图生成对"薄片 + 密集文字"完全无效**——书页这种物体没有体量线索，模型只能瞎猜。
2. 人像类可以出轮廓，但**面部是高糊**，这正是"推断性复原"的边界：能给体量感，不能给相貌。
3. 想要"能看清脸"的文物模型，只有一条路——**多视角摄影测量（COLMAP）**，至少 30 张环绕照片。
4. 渲染预览图存在 `assets/models/preview/`，可直接放进报告或 PPT 当"技术局限性"的证据。

# 八、批量版（2026-10-31 扩产）

把单件流程扩成批处理：**17 件文物 × 单图生成**，全部渲染预览图。

## 8.1 批量结果

| 判定 | 数量 | 说明 |
|---|---|---|
| 可用（fill ≥ 0.12） | **13** | 人像、雕像、纪念墙、旗帜、街垒场景 |
| 薄片（flat） | 2 | 《资本论》初版、第一国际会员证 —— 文献类通病 |
| 失败（fail） | 2 | 马克思故居（塌成薄板）、《宣言》初版（碎面） |

**判定方法**：`fill = 网格体积 / 包围盒体积`（trimesh 实测）。立体雕像通常 0.3–0.6；
塌成薄板会掉到 0.01–0.02；文献类 0.07–0.11 且厚度 < 0.12，肉眼即可看出是"浮雕片"。

## 8.3 结论（可直接写进报告）

1. **人像/雕像/纪念墙 = 高地**：单图生成能给出可用的体量与轮廓，适合做展陈远景、氛围模型。
2. **建筑 = 陷阱**：立面照片信息高度集中在平面上，模型直接塌成薄板（故居 y 向只剩 0.2）。
3. **文献 = 必败**：纸张厚度接近 0，任何单图重建都只能给你一张"浮雕"，不如直接扫描贴图。
4. 因此这一卷的定位应当明确写死：**"体量示意"而非"文物复刻"**，量与尺一律不可引用。

## 8.4 工程细节

- 批量脚本：`/root/in2 → TripoSR → /root/out2 → render_glb2.py → /root/preview2`
- 单件耗时：推理 1–3 秒，导出 + 渲染约 3 秒；14 件全流程 **≈ 2 分钟**（不含上传）
- 模型总量 23.9 MB（17 个 glb），缩略图 17 张（360px，共约 0.6 MB）
- 页面用 `assets/models/models.json` 驱动：加模型只需放 glb + 缩略图 + 一条 JSON，无需改代码
