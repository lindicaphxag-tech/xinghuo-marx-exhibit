# 历史纪录片制作规范（本项目版）

## 一句话

**旁白先录、长度实测、画面按词对齐；能用原物就不用重绘；每个数字都有出处；运动要克制。**

## 一、十二步流程

| # | 步骤 | 产出 | 我们的工具 |
|---|---|---|---|
| 1 | 立论：一句话论点 + 必须出现的材料清单 | 论点句、材料表 | v10 稿已做 |
| 2 | 分镜稿：时间码、名言、故事、图、批注、录法 | 分镜 docx | v10 稿已做 |
| 3 | 旁白先出：按句编号，一句一行 | `vo.json` | edge-tts |
| 4 | 实测每句时长，**不手填** | `vo_durations.json` | ffprobe |
| 5 | 时间线：镜头长度 = 实测句长 + 0.4s 头尾 | `timeline.json` | 脚本生成 |
| 6 | 画面预案：每个镜头标明是「页面录屏 / 原物图 / 引文卡 / 地图接口」 | 镜头表 | — |
| 7 | 采集：只截真的页面与真的档案，不重绘界面 | 帧目录 | Playwright + CDP |
| 8 | 对齐：字幕与批注挂在句子的起点，不按秒切 | 帧 + 字幕表 | 渲染脚本 |
| 9 | 声音：旁白 −16 LUFS 左右，垫乐 −26 LUFS，环境音 −30 LUFS | 混音参数 | ffmpeg loudnorm |
| 10 | 拼接：统一 30fps、恒定帧率、AAC 192k | 母版 | ffmpeg |
| 11 | QA：抽帧联系表逐格看，响度实测，字幕逐句对读 | 联系表 + 报告 | PIL / ffmpeg |
| 12 | 交付：母版 + 无配乐版 + 字幕 srt + 出处清单 | 四件套 | — |

## 二、七条原则

**1. 旁白是时钟。**
先录旁白、量出每句长度，再决定画面停多久。改一个字就要重跑时长，不许手写秒数——手写的帧号一定过期。

**2. 对齐到词，不对齐到秒。**
字幕与批注挂在句子起点；一句没说完不换行。切句用句号，不用字数三等分。

**3. 能用原物就用原物。**
页面就录页面，报纸就放报纸扫描，碑就放碑的照片。重绘只用于「原件不可得」的地方，并且当场标注。

**4. 每个数字都有出处。**
「4,780 篇」「117 条」「九条与一百零八条」这类数字，必须能指向 analysis.json 或原刊期号。凑不出的数字，宁可不写。

**5. 运动要克制。**
推近、缓移、淡入即可；不做弹跳、不做旋转文字、不做快速翻页。纪录片不是短视频。
一个镜头里只允许一种运动。

**6. 用眼睛和耳朵验收。**
每一段抽 3 帧看；每句字幕对读；成品量响度。不看就交付，等于没做。

**7. 语言要对得起材料。**
中文用通行译本（人民出版社/中央编译局），没有通行译本的不摘句；外文原题保留原文并给直译；自撰的规则要标明「自撰，非引文」。

## 三、硬规则

1. **不生成真人**：不合成任何真实人物的图像或影像。真人要么用有授权的原始影像，要么不用。
2. **不造引文**：名言必须能查到出处与译本。查不到就改成叙述，不加引号。
3. **不造媒体标识**：不做假报纸报头、假电视角标。
4. **标注推断**：模型、复原、示意，一律标 E4；实测与推断分开摆。
5. **音乐要有许可**：本项目用公有领域录音（肖邦夜曲，Internet Archive），署名写在片尾。
6. **隐私与授权**：档案图像的使用范围按原始页许可写进交付说明。

## 四、本项目的具体参数

| 项 | 值 |
|---|---|
| 画幅 | 1920×1080，30fps 恒定 |
| 旁白 | zh-CN-YunjianNeural，rate −3% |
| 旁白响度 | 混音后平均 −23 dB，峰值 ≤ −2 dB |
| 垫乐 | −26 LUFS 左右，首尾各 3–8 秒淡入淡出 |
| 字幕 | 按句，22px，底部压暗带内，最长 2 行 |
| 批注 | 左上段落号、右上证据等级、图上引线、底部字幕，共四层 |
| 单段时长 | 26–40 秒；全片 5–6 分钟 |
| 镜头数 | 每段 1 个主镜头 + 0–2 个补充（引文卡、原物图） |

## 五、QA 检查表（每次交付前逐项打勾）

- [ ] 十段字幕与旁白逐句对得上
- [ ] 每段抽 3 帧看过：无黑屏、无错位、无遮挡关键内容
- [ ] 数字与稿子一致（202 / 117 / 9 / 108 / 72 天 / 23 页）
- [ ] 每条名言有译本依据
- [ ] 响度实测通过
- [ ] 片尾署名与许可齐全
- [ ] 无配乐版也导出
