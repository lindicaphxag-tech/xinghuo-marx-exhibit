### 实测（我刚跑通的验证）

用 COLMAP 官方样例集 south-building 抽 30 张做端到端验证：

```
30 张照片 → 特征提取 1.0 分钟 → 穷举匹配 5.6 分钟 → 稀疏重建 0.6 分钟
结果：30/30 张全部注册，14,865 个三维点，位姿与去畸变影像正常输出
```

结论：**脚本可用**，你只要把照片放进 `01_拍胸像\photos\` 就能直接跑。
**但稠密网格这条路在本机走不通**：COLMAP 的 MVS（`patch_match_stereo`）强制要求 CUDA，
无 GPU 版本会直接报 `Dense stereo reconstruction requires CUDA`（4.2 甚至直接崩溃）。
所以本机能做的只有 **SfM 位姿 + 去畸变影像**，也就是 3DGS 需要的那一半。

要出网格，二选一：

| 路线 | 做法 | 成本/时间 |
|---|---|---|
| **A. 租云卡（推荐）** | AutoDL 租 4090，装 CUDA 版 COLMAP，把 `photos` 传上去，一条命令跑完稠密 | ≈2 元/小时，40 张 10–20 分钟 |
| **B. 本机 Meshroom** | 装 Meshroom（AliceVision，GUI），CPU 做 MVS | 免费，40 张约 2–5 小时 |

> 建议：**位姿在本机跑（免费），稠密/训练上云**。云卡按小时计费，只在最后 20 分钟开。

## 二、第一件事：胸像 → COLMAP（40–60 张）

### 拍
按 `04_重建流程与采集清单/拍摄采集SOP.md` 的方案 1：
- 三圈机位：**上 30° 12 张、中间 0° 24 张、下 −30° 12 张**，相邻重叠 **70–80%**
- 固定焦距、ISO 100、f/8、关 HDR/美颜
- 最好用**转台 + 固定机位**：转台每 10–15° 拍一张，共 24–36 张，最省事也最稳
- 背景要纯色（灰/黑布），并且**背景不能跟着转台转**

### 跑
```powershell
cd "C:\Users\HUAWEI\Desktop\马原\工人革命的马克思宣讲_文物3D重建\06_实操工作区"

# 把照片拷进 01_拍胸像\photos\，然后：
.\tools\run_colmap.ps1 -Project .\01_拍胸像 -Quality fast
```

**本机能跑出来的**：`sparse\0`（相机位姿）+ `dense\images`（去畸变影像）。
到稠密那一步脚本会主动停下并提示，因为无 GPU 版 COLMAP 的 MVS 强制要 CUDA。

**判断这次拍得好不好，看 `sparse\0` 就够**：
- `logs\3_mapper.log` 里能看到注册了多少张，30 张全注册 = 拍得合格
- 位姿一旦成功，3DGS 那边就稳了（3DGS 只用位姿，不用 COLMAP 的稠密）

### 看结果
- `01_拍胸像\sparse\0\` ← 位姿，3DGS 用这个
- `01_拍胸像\dense\images\` ← 去畸变影像，3DGS 用这个
- 想在本机看稀疏点云：用 COLMAP.bat 打开 → File → Import Model → 选 `sparse\0`（能看到点云"人影"说明拍对了）
- 如果 `sparse\` 是空的：照片重叠不够 / 有反光 / 背景太干净 → 重拍

> 想要"能 3D 打印的网格"，必须上云跑 CUDA 版 COLMAP 或本机装 Meshroom，见上面第零节。

## 三、第二件事：书本 → COLMAP

书本比胸像难，难点是**薄、反光、纸面纹理弱**。

拍法（按 SOP 方案 2）：
1. **平放俯拍**：正上方 1 张，四角都要进画面（这张决定正射贴图）
2. **45° 斜拍**：绕书 8 个方位 × 2 个高度 = 16 张
3. **侧拍书脊**：左右各 3 张，表现厚度
4. **翻开**：内页 3–5 个跨页各拍 1 张（做贴图用）

```powershell
.\tools\run_colmap.ps1 -Project .\02_拍书本 -Quality standard
```

> 书本如果重建出来是"波浪面"，是因为纸张不平 —— 拍的时候用亚克力板压平，或者改用「正射照片 + 置换贴图」的做法，不强求 MVS。

## 四、第三件事：雕像 → 视频 → 3DGS（需要 GPU）

### 本机做不了，原因
3DGS 训练要 CUDA。本机没有 NVIDIA 卡（`nvidia-smi` 没有），所以**这一步必须借 GPU**。

### 两条路

**A. AutoDL 租卡（推荐，便宜、国内快）**
1. 注册 autodl.com → 租一台 **RTX 4090 / 3090**（约 1.5–2 元/小时）
2. 选镜像：`PyTorch 2.1 + CUDA 11.8`
3. 上传视频或照片，然后：
```bash
git clone https://github.com/graphdeco-inria/gaussian-splatting --recursive
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
pip install -r gaussian-splatting/requirements.txt
pip install gaussian-splatting/submodules/diff-gaussian-rasterization gaussian-splatting/submodules/simple-knn
# 有现成 COLMAP 位姿就直接用，没有就先在本机跑 run_colmap.ps1 再把 sparse/0 + images 传上去
python gaussian-splatting/train.py -s <数据目录> -m output/statue --iterations 30000
```
**省钱技巧**：位姿（COLMAP）在本机 CPU 上跑完，只把 `sparse/0` + `images` 传上去训练 —— GPU 只干最后 20 分钟的活。

**B. Colab（免费但会断）**
`!git clone ...` 同上，注意免费版显存 15 GB，图多要降分辨率。

### 拍视频的要点
- 4K / 60fps，**绕雕像走 2–3 圈**（不同高度各一圈），每圈 15–20 秒
- 走慢、走稳，不要变焦，不要停下来（停会产生重复帧）
- 一圈大概 300 帧，抽 2 fps 就够

```powershell
# 手机视频 → 抽帧（本机就能跑）
.\tools\video2frames.ps1 -Video .\03_雕像视频\video\statue.mp4 -Fps 2
# 然后照常跑 COLMAP 拿位姿（CPU 也能跑，只是慢）
.\tools\run_colmap.ps1 -Project .\03_雕像视频 -Quality fast
```

### 出网页漫游
训练完的 `point_cloud/iteration_30000/point_cloud.ply` 拖到 <https://supersplat.dev/> → 裁掉背景 → Export `.splat` → 嵌进课程网页。

## 七、排错

| 现象 | 原因 | 处理 |
|---|---|---|
| `sparse` 空 / 只注册几张 | 重叠不足、反光、背景单调 | 补拍，重叠提到 85%，加纹理背景 |
| 报 `Dense stereo reconstruction requires CUDA` | 无 N 卡 | 正常，本机只能做位姿；网格上云或装 Meshroom |
| 模型"炸开" | 有移动物体 / 反光 | 撤掉会动的东西，重拍 |
| 尺寸不对 | 没放标尺 | 拍摄时放一把尺入镜 2 张，后期按已知尺寸缩放 |
| 脚本跑不了/中文乱码 | .ps1 编码 | 已存为 UTF-8 BOM；若改过文件请保持 BOM |
