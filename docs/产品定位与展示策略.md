# 产品定位与展示策略

## 一句话定位

**一座用地图、组织网络、报刊、事件时间线和历史空间，带观众追问“分散的工人如何成为一场运动”的互动数字展馆。**

对外介绍先讲观众能理解的问题，再给体验入口，最后说明资料规模和技术实现。功能清单适合帮助深入了解，不适合作为第一印象。

## 对标 GitHub 优秀项目的展示方法

| 参考项目 | 值得借鉴的产品展示方式 | 在本项目中的对应做法 |

## 产品叙事骨架

### 核心问题

分散在城市、工厂和报刊中的工人，如何成为一场跨越国界的运动？

### 四层历史逻辑，九个自动讲解节点

**生产条件与矛盾 → 理论自觉与共同认识 → 组织实践与历史经验 → 证据层级与开放历史**

九个节点依次落在叙事地图、织工行动、文本、关系网络、报刊、公社、运动分布、证据复原和开放式终章。自动滚动把媒介本身变成论证顺序：先看到劳动条件，再追问理论与组织怎样进入实践，最后辨认材料的存在层级和解释边界。纱线进度线标示关系逐步织密；终章粒子不聚成封闭纪念碑，而向不同方向延伸。

### 三层参观深度

| 层级 | 时间 | 观众任务 | 主要入口 |
|---|---:|---|---|
| 初见 | 30 秒 | 看懂主题与视觉方向 | 门厅、首屏问题、主 CTA |
| 主线 | 约 3 分钟 | 自动走完四层九节点，理解矛盾如何展开 | 自动导览条、旁白视频与章节跳转 |
| 深入 | 10–15 分钟 | 按兴趣追踪证据和空间 | 卷宗、原刊、展品目录、空间目录 |

## 推荐展示脚本

### 15 秒：建立兴趣

“分散在城市、工厂和报刊中的工人，如何成为一场跨越国界的运动？这座数字展馆把问题变成一段可以亲自走过的历史：从城市现场出发，经过组织、传播和行动，最后回到档案与空间。”

### 3 分钟：让观众走完一条线

播放[四层自动讲解视频](../video-tour.html)，或在首页启动网站自动导览。讲解重点不是逐个报功能名，而是串起认识过程：生产条件显现现实矛盾，经验在传播与争论中被概括，理论进入组织和集体实践，历史材料及其局限再反过来约束解释。用户可以暂停、跳段，或点视频章节直接进入某一层。

### 收尾：把观看转成探索

“你可以从地图、人物、报刊或空间中的任一条线索继续走下去；展馆先给出路径，馆藏入口保留继续追问的方向。”

逐站的操作目标、讲解词、转场、90 秒压缩方案和现场备选方案见 [`展示与讲解手册.md`](展示与讲解手册.md)。

## README 与演示素材策略

- **第一屏：**一句项目定位、展馆实景和“开始 3 分钟导览”的明确入口。
- **第二屏：**一张完整首屏图，说明主叙事问题；再用四张图展示地图、关系网络、公社时间线和展品。
- **快速开始：**提供最短启动路径，把平台差异和故障备选放在紧邻位置。
- **深读入口：**把空间、展品、文档、许可证和部署分开，避免首次访问被技术细节淹没。
- **答辩顺序：**地图、关系网络、巴黎公社、原刊或空间；每个镜头只演示一个动作。
- **画面规范：**截取真实页面、统一浏览器视口和命名；截图聚焦解释中的界面，不让导览浮层或浏览器杂项挡住内容。

当前 README 已加入桌面/手机入口、门厅和四个核心展项截图；素材保存在 `video/shots/`，讲解手册给出截图和短视频顺序。

## 适合首页、答辩和项目介绍的短文案

### 一句话

**从街垒到报刊，从工厂到组织网络——走进工人运动成为跨国历史的过程。**

### 项目摘要

“星火与道路”是一座可离线运行的互动数字展馆。观众通过四层九节点自动导览，沿生产条件、理论自觉、组织实践和认识方法理解 1831—1917 年工人运动的历史联系；需要深入时，可继续进入文献、图像、模型和空间目录。

- 视频入口：**观看完整自动讲解视频**
- 次按钮：**自由进入叙事**
- 目录入口：**直接查阅档案与展品**

## 展示前检查

- 从 `hall.html` 开始，确认“进入主展馆”可到达叙事首页。
- 首屏启动四层九节点自动导览，或打开带字幕、章节跳转和讲稿的视频页；深入展示时再选定人物节点、报刊期号、公社切片和一个空间展项。
- 投屏用的浏览器窗口先打开，切换大模型前留出加载时间。
- 使用随包本地资源；外部原刊不可访问时，继续展示内置章节内容和档案入口。
- 发布页面时先检查首页截图、启动说明、部署路径、素材来源与许可说明是否和实际包体一致。
