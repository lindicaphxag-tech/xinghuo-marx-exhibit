## 建议的执行顺序（按"能出成果"排序）

1. **第 1 周**：拍胸像（#8）。40–60 张照片，COLMAP 跑通，产出第一个 `.obj`——建立信心与流程。
2. **第 2 周**：拍一本书（#1 或 #2 的复制品/影印本）。练"薄片物体 + 翻页 + 正射纹理"。
3. **第 3 周**：雕像（#6 或 #9）用手机视频环绕，跑 3DGS，做网页漫游。
4. **第 4 周**：单图生成（Hunyuan3D/TRELLIS）做 #14 圣马丁堂的"推断复原"体块，与版画同角度叠合出图。

## 关于"没有实物怎么办"

课程作业大概率拿不到真文物。三个合规替代方案：

1. **复制品/影印本**：国家图书馆、版本馆、纪念馆的公开影印出版物，拍复制品并在报告中注明"据影印本重建"。
2. **公开数据集**：Sketchfab 上 CC BY 的马克思雕像扫描件（见 `05_参考案例与已有3D资源/`），下载后做**再处理与比对**，研究"重建精度评价"而不是"从零重建"。
3. **生成式推断复原**：单图/单画 → Hunyuan3D-2 / TRELLIS，明确标注"AI 推断，非实测"。

> ⚠️ 学术红线：把生成模型的结果说成"文物三维扫描"，是思政课 + 数字人文双重意义上的硬伤。
