# 拍摄采集 SOP（文物向）

> 目标：拍出一套"能跑通 COLMAP"的照片。**照片质量决定 80% 的最终效果**，剩下 20% 才是软件调参。

## 一、器材清单

| 类别 | 必备 | 加分 | 说明 |
|---|---|---|---|
| 相机 | 手机（≥1200 万像素，关 HDR/美颜） | 微单 + 50 mm 定焦 | 定焦比变焦好，畸变小；**全程锁定焦距** |
| 稳定 | 三脚架 / 简易云台 | 电动转台（¥100 内） | 转台让"环绕"变成"转物"，效率翻倍 |
| 光 | 两盏柔光灯或阴天户外散射光 | 偏振片、灰卡、标尺 | **绝对不要直射闪光灯 + 硬阴影** |
| 背景 | 纯色哑光布（灰/黑） | 无影背景纸 | 背景越干净，特征匹配越准 |
| 其他 | 快门线/定时 2 s | 反光板、亚克力压板（拍书） | 压板用于报刊、纸张 |

## 二、拍摄参数（照抄即可）

```
模式：M 档 / 专业模式（不要用自动）
ISO：100（固定）
光圈：f/8 – f/11（景深足够覆盖物体）
快门：≥ 1/60 s（室内用灯时 1/30 也可以，但必须三脚架）
白平衡：固定（5000–5500K），不要自动
对焦：单点对焦在物体中心，锁定后不再变焦
格式：RAW + JPEG（RAW 用于后期统一曝光）
分辨率：最高（不要裁切、不要数码变焦）
```

## 三、机位布置（三种物体的三套方案）

### 方案 1：小器物 / 胸像（最常用）
```
        上圈 30°（12–16 张）
      ┌──────────────────┐
      │   中圈 0°（24 张）  │   ← 主体，最重要
      └──────────────────┘
        下圈 -30°（12–16 张）
```
- 每圈**等角度**旋转，相邻照片重叠 **70–80%**
- 小物件建议 **转台 + 固定机位**：转台每转 10–15° 拍 1 张，共 24–36 张
- 顶部补 4–6 张（俯拍），底部若不可见可不拍

### 方案 2：书本 / 平面文物
1. **平放**俯拍：正上方，四角都要拍到，作为正射基准
2. **45° 斜拍**：绕书 8 个方位，每方位 2 张（高/低角度）
3. **翻开**：拍内页 3–5 个跨页，每页正对拍 1 张（做贴图用）
4. **侧拍书脊**：左右各 3 张，表现厚度与弧度

### 方案 3：大型雕像 / 建筑
- **视频法**：4K 60 fps，绕行 2–3 圈（不同高度），每 5 帧抽 1 帧 → 约 200–300 帧
- **分段拍**：长焦分上半身、下半身、基座，避免广角畸变
- **禁忌**：不要在同一次采集里混用不同焦段（COLMAP 会崩）

## 四、布光（决定成败）

| 物体类型 | 布光方案 |
|---|---|
| 一般石/木/石膏 | 两盏 45° 柔光，主光:辅光 = 2:1，加反光板补暗部 |
| 青铜/金属/釉面 | **加偏振片**（镜头 + 灯各一片，交叉偏振去高光）；或改用大面积柔光箱 |
| 浮雕/铭文 | **掠射光**：灯压到 10–20° 侧打，让起伏出阴影；同时补一遍顺光拍纯色贴图 |
| 纸质/织物 | 两侧对称柔光，避免纸张反光；用亚克力压平 |
| 玻璃/透明 | 最难，建议跳过摄影测量，直接用 3DGS 或买现成模型 |

**背景要"会动"**：如果用转台，背景必须相对相机静止（把背景布固定在地面，不要让转台带着背景转），否则 COLMAP 会把背景当特征点。

## 五、现场检查清单（拍完立刻核对）

- [ ] 每张都清晰（放大 100% 看边缘，无抖动）
- [ ] 曝光一致（不忽明忽暗，RAW 后期可统一）
- [ ] 白平衡一致
- [ ] 物体占画面 70% 以上
- [ ] 有 **尺度参照物**（一把尺 / 一枚硬币 / 已知尺寸的卡片）入镜至少 2 张
- [ ] 有 **色彩参照**（灰卡）
- [ ] 没有拍到自己的影子 / 三脚架 / 反光
- [ ] 文件按 `objName_ring01_0001.jpg` 命名，便于排查

## 六、常见失败与对策

| 现象 | 原因 | 对策 |
|---|---|---|
| COLMAP 只注册了部分照片 | 重叠不足 / 纹理弱 | 补拍、提高重叠到 85% |
| 模型"炸开"成两团 | 有反光或移动物体 | 重拍，去反光，撤掉会动的东西 |
| 表面全是"橘皮" | 照片糊 / 噪点高 | 提高快门、降 ISO、用三脚架 |
| 尺寸不对 | 无尺度参照 | 加标尺重拍，或后期按已知尺寸缩放 |
| 书本变成"波浪" | 纸张不平 | 亚克力压平；或用正射 + 置换贴图 |
| 金属表面出现黑洞 | 高光溢出 | 交叉偏振 + HDR 包围 |

## 七、伦理与合规（文物类必须写进报告）

1. **不接触文物本体**：博物馆展柜内文物一律隔着玻璃拍，不使用闪光灯（很多博物馆明令禁止）。
2. **不使用显影剂/喷粉**：会损伤文物表面。
3. **遵守场馆规定**：拍摄前询问是否允许摄影、是否允许用于课程作业。
4. **复制品标注**：使用复制品/影印本时，报告中必须注明"据复制品重建"。
5. **人物肖像**：若画面中有游客，公开传播时需打码。
