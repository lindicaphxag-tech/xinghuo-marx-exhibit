# 历史资料搜集总账

> 版本：2026-11-02。范围按展馆实际主题“工人运动与马克思主义传播”及现有叙事结构整理，主时间线为 1831—1917 年；理论背景回溯至 1818 年，记忆与影响延伸至当代。当前已完成的交付口径：12 个展区均已接入来源卡，共 61 项来源入口；本地可合法复用的《Bee-Hive》两年 OCR 数据包已落盘并接入逐期阅读器。这里的“搜集全”是本展范围内关键证据类型、代表事件和可追溯入口覆盖完成，不声称穷尽全球所有相关馆藏，也不将仅可在线查阅或权利不明的馆藏擅自复制进离线包。

## 1. 现有资产盘点

统一资产目录生成口径为 310 条记录：18 份文献、73 张图像、63 个文物单图推断模型、9 个漫游体验、16 个空间模型记录及 131 条交互数据记录。现有图像来源、作者、许可、本地路径见 [`来源与授权.md`](来源与授权.md) 和 [`source_manifest.json`](../assets/sources/source_manifest.json)；历史空间来源及证据等级见 [`空间实景重建工作流.md`](空间实景重建工作流.md)、[`scenes.json`](../assets/scenes/scenes.json)；统一对象索引见 [`registry.json`](../assets/manifests/registry.json) 与 [`asset_catalog.json`](../assets/manifests/asset_catalog.json)。12 个叙事章节均有“本卷史料与馆藏入口”折叠索引，共 61 项；《Bee-Hive》在卷四内可直接按年份、日期和关键词阅读离线 OCR 原文。

既有资产不等于每种报刊都有完整原刊，也不等于 63 个模型都是真实扫描。单图模型属于推断性表达；空间资产需区分实测现状、历史馆藏模型、史料约束复原和概念模型。上述证据等级不因新资料链接而改变。

## 4. 逐项资料卡字段（新增采集统一使用）

每项至少记录：`source_id`、展卷 ID、事件/主题、标题、作者/机构、原始日期、出版地/地点、馆藏编号或 ARK/DOI、原件类型（扫描/转录/目录/复原）、完整度、文件 URL、本地路径、许可原文和许可 URL、署名、下载日期、SHA-256、解释性说明、证据等级、关联人物/组织/事件、复核人/复核日期。缺一项就标 `unknown` / `online-only`，不猜填。

## 5. 离线和权利边界

- 网站静态页面、JS/CSS、登记的图片与模型、离线文献可打入整站目录；外部馆藏阅读器、地图瓦片和第三方 3D 查看器仍需网络，除非把对应合法开放数据完整下载并配置本地服务。
- CC0/Public Domain 文件可按来源页面约定离线复用；CC BY/CC BY-SA 需带作者与许可文本；馆藏页面仅供在线访问的图像不可自动镜像；原始档案扫描的“可下载”不等于“可公开再发布”。
- 数据按实物证据等级标注：E1 现场实测/摄影测量，E2 有明确授权的第三方模型，E3 同期图像/原件数字化，E4 受史料约束的推断性复原。历史空间页面继续区分现状和历史年代。

## 6. 已完成范围与不可冒称完成的边界

本展的信息架构、来源入口和可离线复用的核心全文已落到页面：章节来源卡可直达原始馆藏或本地资料；《Bee-Hive》两包共 16,170,421 字节，来源登记含 DOI、许可和 SHA-256，索引覆盖 65 个日期期次、4,780 篇 OCR 文章。网页静态资产和已登记本地文件可随项目离线部署；外部馆藏原件、受访问控制的数字阅读器、联网地图服务仍要求网络。

以下属于馆藏覆盖/现场采集条件的客观边界，已在相应页面或目录标明，不能通过界面开发虚构成“全部数字化”：

1. 1844 西里西亚织工起义：当前入口是博物馆历史概述，不能替代同期文书；1889 巴黎国际工人大会当前链接是后期转录/译本，不能替代 IISG/Guesde 档案原件。Haymarket、1905、1917 等入口按其馆藏记录提供个案材料，不代表覆盖该事件全部档案。
2. 《新青年》《新莱茵报》《社会民主党人报》《火星报》等尚非全刊逐期本地数字化；页面只把能核验的扫描列为代表期号，缺期不会伪造封面。《Bee-Hive》也只覆盖 1862、1872 两个年份的馆方选集，不是完整报刊全量。
3. 地图事件点受史料、历史地址转译与现有数据精度限制。热力/密度是展陈编码，不能误读为完整人口或行动次数统计；需要逐点坐标或配准误差的场景已在来源说明中标边界。
4. 63 个单图推断模型不是实物扫描；被毁场所没有可供扫描的原建筑。现存地点的现场高精度摄影测量仍需现场采集、设备/许可和尺寸验证；模型与空间目录明确区分推断、馆藏模型、现状扫描和史料约束复原。

## 7. 总账复核方法

在源站确认链接仍可访问、馆藏号与展品叙述吻合后，再把条目标记为“已核验”。发布前按 `rights_status` 过滤许可；离线包要保留本文件、来源清单、许可文本、原始文件与校验值。现有图像清册可由 `python scripts/sync_sources.py` 更新，资产目录可由 `node scripts/build_asset_catalog.js` 重建，核查报告按 `python scripts/audit_asset_catalog.py` 生成。
