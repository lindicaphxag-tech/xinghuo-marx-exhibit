# 重建流程 · 命令行手册（Windows）

> 假设工作目录：`D:\work\statue\`，照片在 `images/`。所有命令在 PowerShell 里执行。
> 先做一件事：把 COLMAP 的 `bin` 目录加进 PATH，验证 `colmap -h` 能出帮助。

## 一、COLMAP：照片 → 位姿 → 稠密点云 → 网格

```powershell
cd D:\work\statue

# 1) 特征提取（单相机模型，所有照片同一台机）
colmap feature_extractor `
  --database_path .\db.db `
  --image_path .\images `
  --ImageReader.camera_model OPENCV `
  --ImageReader.single_camera 1 `
  --SiftExtraction.use_gpu 1

# 2) 匹配（照片少用 exhaustive，多且有序用 sequential/vocab_tree）
colmap exhaustive_matcher --database_path .\db.db --SiftMatching.use_gpu 1

# 3) 稀疏重建（SfM）
colmap mapper --database_path .\db.db --image_path .\images --output_path .\sparse
# 结果在 .\sparse\0\，看到 cameras.bin images.bin points3D.bin 就成功

# 4) 去畸变 + 导出给 MVS（max_image_size 2000 是精度/显存折中）
colmap image_undistorter `
  --image_path .\images `
  --input_path .\sparse\0 `
  --output_path .\dense `
  --output_type COLMAP `
  --max_image_size 2000

# 5) 稠密匹配（这一步最吃显存/时间）
colmap patch_match_stereo `
  --workspace_path .\dense `
  --workspace_format COLMAP `
  --PatchMatchStereo.geom_consistency true

# 6) 融合点云
colmap stereo_fusion `
  --workspace_path .\dense `
  --workspace_format COLMAP `
  --input_type geometric `
  --output_path .\dense\fused.ply

# 7) 出网格（二选一）
colmap poisson_mesher --input_path .\dense\fused.ply --output_path .\dense\meshed-poisson.ply   # 更光滑，适合雕像
colmap delaunay_mesher --input_path .\dense --output_path .\dense\meshed-delaunay.ply           # 更保真，适合带文字/浮雕
```

**并行速度**：`--PatchMatchStereo.max_image_size` 可以调到 1600 换速度；`--PatchMatchStereo.gpu_index 0,1` 多卡。

## 二、OpenMVS：把点云变成"带贴图的干净网格"（推荐补这一步）

```powershell
# COLMAP dense → OpenMVS 工程
InterfaceCOLMAP -i .\dense -o .\scene.mvs --image-folder .\dense\images

DensifyPointCloud .\scene.mvs                      # 若已有 fused.ply 可跳过
ReconstructMesh .\scene.mvs -p .\dense\fused.ply   # 网格化（带孔洞填充）
TextureMesh .\scene.mvs --export-type obj          # 生成带 mtl + 贴图的 obj
```

产物：`scene_mesh.obj` + `scene_mesh_material_0_map0_0.jpg`（4K 贴图）。

## 三、3D Gaussian Splatting：真实感漫游

```powershell
git clone https://github.com/graphdeco-inria/gaussian-splatting --recursive
cd gaussian-splatting
conda activate gs

# 直接用 COLMAP 的 sparse/0 + images（脚本会自动整理成 data/ 结构）

python train.py -s D:\work\statue\data -m D:\work\statue\output\bust --iterations 30000

# 看结果
.\SIBR_viewers\bin\SIBR_gaussianViewer_app.exe -m D:\work\statue\output\bust
```

**导出网页版**：
1. 打开 https://supersplat.dev/ → 拖入 `output/bust/point_cloud/iteration_30000/point_cloud.ply`
2. 编辑（裁剪多余背景）→ Export → 选 `.splat` 或 `.glb`
3. 用 `<script type="module" src="https://unpkg.com/gsplat.js"></script>` 或 SuperSplat 导出的 HTML 模板嵌进课程网页

**要可打印的网格**：接 `SuGaR` 或 `2DGS`，从高斯提取表面对齐网格，再进 Blender 重拓扑。

## 六、Blender 收尾（可脚本化）

`blender --background --python clean.py`，`clean.py` 示例：

```python
import bpy, sys

src = r"D:\work\statue\dense\meshed-poisson.ply"
bpy.ops.wm.read_factory_settings(use_empty=True)
bpy.ops.import_mesh.ply(filepath=src)

obj = bpy.context.selected_objects[0]
mod = obj.modifiers.new("dec", 'DECIMATE')
mod.ratio = 0.25                     # 100 万面 → 25 万面
bpy.ops.object.modifier_apply(modifier=mod.name)

# 填孔 / 修非流形交给 3D Print Toolbox + Remesh（可视化操作更稳）

bpy.ops.export_scene.gltf(filepath=r"D:\work\statue\bust.glb", export_format='GLB')
```

常用插件：`3D Print Toolbox`（检查非流形、厚度）、`MeshLab`（外部清理）、`UV Packmaster`（可选）。

## 七、精度比对（CloudCompare）

1. 打开 CloudCompare → 拖入 `meshed-poisson.ply`（被测）与参考模型（如 Sketchfab 的 CC BY 扫描件）
2. 选两个对象 → `Tools > Registration > Fine registration (ICP)` 对齐
3. `Tools > Distances > Cloud/Cloud Dist` → 计算 C2C 距离
4. 读 `mean / std / RMSE / 95%` 分位数 → 写进报告
5. 截图色阶图（红=误差大）作为"精度评价"插图

## 八、常见报错速查

| 报错 | 原因 | 解决 |
|---|---|---|
| `No good initial image pair found` | 照片重叠不足 / 背景太干净 / 顺序乱 | 提高重叠，加纹理背景，`--Mapper.init_min_num_inliers` 调低 |
| COLMAP 只注册 30% 照片 | 有反光/运动物体/曝光差异大 | 重拍，去反光，统一曝光 |
| `CUDA out of memory` | 分辨率或点太多 | `--max_image_size 1600`，`PatchMatchStereo.max_image_size` 降低 |
| `diff-gaussian-rasterization` 编译失败 | 缺 VS Build Tools / CUDA 版本不匹配 | 装 VS 2022 C++ 工作负载 + CUDA 11.8，`set DISTUTILS_USE_SDK=1` |
| 3DGS 训练后一片糊 | 位姿不准（COLMAP 失败） | 先确认 sparse 重建质量，再训练 |
| OpenMVS `TextureMesh` 贴图错位 | 大图 + 内存不足 | 降 `--max-image-size 2048`，分块纹理 |
| `ns-process-data` 卡住 | 未装 colmap 或 ffmpeg | `conda install -c conda-forge colmap ffmpeg` |

## 九、一键顺序（照这个顺序做就不会乱）

```
拍 → COLMAP(1–7) → OpenMVS(可选,出贴图网格) → Blender 修 → 交付 .obj/.glb
                                    ↘ 3DGS 训练 → SuperSplat 导出 → 网页漫游
                                    ↘ CloudCompare 比对 → 精度表
```
