# 空间实景采集、重建与史料编目工作流

> 当前项目状态（2026-11-01）：空间目录现有16条：3条来源站摄影测量扫描、4条本地当代 LiDAR 地形/表面模型、7条史料约束历史复原；其余条目包括现状点云、现址地图和室内全景。全景与现址地图不等同于可测量网格扫描。这里的“现场”数据表示采集时的现状，不等于所述历史年代。以下旧记录按时间保留；被毁场所不能称为原址实景扫描。

本文用于把现有“概念空间”与可核验的实景扫描区分开，并为后续采集提供可执行流程。实景重建不等于历史复原：照片或视频只能记录采集时可见的空间。

## 1. 先确定要表达什么

每个空间条目先写清目标：现存建筑/遗址的现状记录、建筑内部导览、历史场景的证据约束复原，或仅用于教学的概念模型。前三类不能共用同一种标签。历史复原的每个关键构件都应对应来源或标为推断；视觉逼真度不是史实证据。

## 2. 现场影像采集

1. 获得场地拍摄许可，确认人物隐私、版权和安全限制；保留原始素材和许可记录。
2. 用手机或相机拍摄连续、清晰、曝光稳定的视频，缓慢环绕空间；对重要物件和立面补拍多角度照片。相邻视角应有充分重叠，且整个空间应形成闭合或多条交叉路径。
3. 同时拍摄全景与细节，避免只拍单面；玻璃、镜面、纯色墙、快速移动人群和快速摇镜都会增加重建困难。
4. 用卷尺、测距仪或已知尺寸物件提供尺度参照；记录设备、焦段、日期、天气、路线、方位及遮挡。避免把隐私信息直接放入公开模型。
5. 把原始文件做只读备份，保存文件清单和校验值。不要只保留压缩后模型。

## 3. 从影像生成 Gaussian Splat

可采用开源 Nerfstudio Splatfacto 等训练流程。常见步骤为：安装匹配的 Python、CUDA 与 PyTorch 环境；使用 `ns-process-data video` 或 `ns-process-data images` 整理影像并估计相机位姿；运行 `ns-train splatfacto` 训练；用 `ns-viewer` 检查覆盖范围、漂浮伪影和尺度；导出 PLY，再用 SuperSplat 检视、裁切、压缩并导出浏览器所需格式。不同 GPU、软件版本与命令参数会变化，应以各项目当前官方文档为准。

训练通常需要 NVIDIA GPU 与较大显存。显存不足时减少输入分辨率、训练图像数量或采用较轻的配置；不要删掉原始高分辨率数据。把环境锁定文件、命令、模型检查点和导出配置与素材一起归档，便于重现。

## 4. 浏览器审阅与发布

在展馆中打开“高保真实景扫描工作台”，选择或拖入 `.ply`、`.spz`、`.sog`、`.splat`、`.ksplat`、`.rad` 或 `.zip` 文件。模型在浏览器本地读取，不会自动上传。模型过大或浏览器显存不足时，先用 SuperSplat 降采样/压缩，再重新导入。发布前需在目标设备检查加载耗时、方向、比例、透明伪影、遮挡和浏览器兼容性。

当前展馆的查看器基于 Spark 2.4.0 与独立 Three.js r180 页面，主展馆仍使用 Three.js r147。该查看器负责展示既有 Gaussian Splat，并不在浏览器内训练模型。

## 5. 历史场景的证据边界

已不存在的 19 世纪空间不能用现代现场扫描代替。建立复原模型时，按证据层拆分：

- **可核验事实**：有测绘图、照片、考古记录、建筑档案或多项一致文字材料支持。
- **合理推断**：与已知年代、建筑类型和地点条件相符，但缺少直接证据。
- **未知/争议**：没有足够材料或史料互相冲突。

在展项里用不同样式显示推断和未知部分，附上来源名称、页码/档号、链接、引用范围与访问日期。不要把 AI 生成图像、风格化场景或现代建筑扫描标成“历史实景”。

## 开源工具

- [Nerfstudio](https://github.com/nerfstudio-project/nerfstudio)：影像准备与 Gaussian Splat 训练。
- [SuperSplat](https://github.com/playcanvas/supersplat)：浏览器中的 Splat 编辑、检查与优化。
- [Spark](https://github.com/sparkjsdev/spark)：Three.js 场景中的 Gaussian Splat 渲染，本项目工作台采用独立页面隔离版本。
- [AliceVision Meshroom](https://github.com/alicevision/meshroom)：摄影测量与纹理网格流程，适合需要可测量表面网格的场景。

前沿仓库筛选、许可证风险与本项目适配顺序见[GitHub 前沿历史空间重建技术调研](GitHub前沿历史空间重建技术调研.md)。重点补充 3D Tiles 地理瓦片、超大点云、多视角网格、CityJSON 历史街区模型与 2D Gaussian / mesh 混合表示。

## 追加核查：补齐可用的圣马丁堂室内史料，并更正斯莫尔尼扫描对象（2026-11-01）

- **圣马丁堂**：伦敦博物馆藏品 NN28188 提供 1850—1851 年集会厅版画，馆方许可标注 CC BY-NC 4.0，并开放 1355 × 1920 下载图。展厅证据卡现展示版画，标注馆藏号、年代、署名和非商业许可，并链接回馆藏页。该版画为二维史料；它不能等同于实景扫描或完整三维复原。其已知主厅尺寸（121 英尺 6 英寸 × 55 英尺 5 英寸 × 40 英尺）可用于后续建模校准；尺寸来自 John Timbs 的 1867 年建筑记述，仍需以建筑原图交叉核对。伦敦博物馆藏品记录：[NN28188](https://www.londonmuseum.org.uk/collections/v/object-979088/st-martins-hall/)。
- **斯莫尔尼**：2020 年确有斯莫尔尼建筑群内的高精度激光扫描公开项目说明，使用 FARO Focus 3D X330，并制作高、中分辨率 OBJ；但其扫描对象是斯莫尔尼大教堂（Smolny Cathedral），不是 1917 年布尔什维克总部所在的斯莫尔尼学院主楼。该项目页面没有公开模型下载，也未提供开放再利用许可。故本项目只把它作为相邻建筑群的扫描线索，不将其标成总部模型；需要联系项目方申请数据与许可，再针对学院主楼现场采集。[项目方扫描说明](https://photogrammetria.ru/358-geodezicheskie-i-fotogrammetricheskie-obmery-smolnogo-sobora-i-ego-maketa.html)。
- 追加艾尔米塔什藏夸伦吉1806—1808年主立面中部/墙体详图（ОР-9648）及Public Domain Mark缩图，展厅可切换对照；这不是完整全楼平面。根据圣彼得堡建筑资料，将模型中央门廊柱数由六柱修正为八柱，并加入现状照片中可见的首层连续拱券表达。交互时间线区分1917总部使用与1923—24入口改造、1927纪念像、1933—34喷泉，避免将后期景观当作革命现场。
- **展厅实现**：圣马丁堂证据卡新增室内史料图与单独的许可/馆藏链接；场景来源支持额外的相关扫描来源条目，避免把相邻建筑的扫描与目标历史空间混为一谈。当前16条空间均明确标注数据性质：Mytholme Mill遗址、重建后的巴黎市政厅和1909年纪念碑可直接嵌入来源站实扫；另有LiDAR、点云、全景及历史复原分别展示。

## 圣马丁堂1864年场景的年代校正（2026-11-01）

历史核查发现，不能把1850—1853年的圣马丁堂状态直接等同为第一国际成立大会现场：1860年8月26日火灾摧毁了原堂；历史资料记载会堂后来重建，并于1862/63年前后重新开放；第一国际成立大会于1864年9月28日在圣马丁堂举行。因此场景时间轴现已拆分为原堂开放、1853扩建、1860火灾、火灾后重建、1864大会和1867剧院改建。

当前 GLB 几何仍以《The Builder》1853年主厅与附属空间尺寸作比例参照，没有重建后完整平面图或实测依据。目录现已将其明确标注为“1864重建期会堂的证据约束教学复原”，不把旧厅尺寸写成已核实的新厅尺寸。后续若取得1862/63年重建图、照片或可靠测绘，应据此替换现有几何。核查来源：[House Divided 的1860年火灾条目](https://hd.housedivided.dickinson.edu/node/33533)、[第一国际成立大会记述](https://marxists-malta.org/archive/braunthal/history-international/vol1/9founding.htm)。

展厅三维场景的年代按钮目前只切换史料文字，不会切换 GLB 几何。界面已加提示，明确告知观众这一点，避免把时间叙述误解为历史模型逐年代变化。旧址与现状建筑在清单中作为独立场景切换；尚无独立年份模型的地点不伪装成可变时空数字孪生。
